# Credential Wallet con React + JOSE

Proyecto educativo que simula una **Wallet de Credenciales** digitales utilizando React y la librería JOSE para gestión de identidades con JWT.

La aplicación permite:

- Crear múltiples credenciales
- Firmarlas digitalmente con JWT
- Verificar su autenticidad
- Gestionar distintos emisores
- Guardar credenciales localmente mediante `localStorage()`

---

## Tecnologías

- React
- Vite
- JOSE
- CSS3
